WEBSITE SINH NHAT CHO NHANH - made by tntl
===========================================

DAY LA BAN DA CA NHAN HOA TU FILE birthday-letter-my-dearest-nhanh (1).zip
- Da giu ten, loi chuc, 4 hinh, caption, nhac MP4, lyrics, theme va hieu ung.
- Da dua noi dung cua script.js va config.js vao CUOI file index.html.
- Goi ZIP moi KHONG co file *.js rieng, nham tranh canh bao voi file .js khi giai nen.
- Khong can tai them customize.html; day la ban de up thang len GitHub Pages.

CACH SU DUNG
1. Giai nen ZIP moi va mo index.html bang Chrome de kiem tra.
2. Tao repository moi tren GitHub va chon Public.
3. Upload index.html + style.css + assets/ len thu muc goc repository.
   Dung upload nguyen file zip, va khong them mot cap thu muc cha.
4. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. Sau khi duoc cap URL, mo link va kiem tra hinh anh, am thanh, loi bai hat.

LUU Y
- Nen scan ZIP bang Microsoft Defender truoc khi mo.
- Neu van bi canh bao, dung lai va xem Windows Security -> Protection history,
  khong tat Defender va khong can chon 'Allow threat'.
- Trang nay dang cong khai tren GitHub Pages neu repository la Public;
  nguoi khac co the xem/luu anh va nhac.
- Neu muon doi noi dung, mo index.html voi VS Code va tim 'window.BIRTHDAY_CONFIG'.
- Nhac trong ban goc la assets/your-song.mp4; browser chi phat sau khi nhan Play.
- Khong upload file customize-lite.html; ZIP nay chi gom nhung file can cho web.
